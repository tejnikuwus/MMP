# MMP (Модульна багатозадачна платформа)

**MMP (Modular Multitask Platform)** — це інноваційний гібридний робототехнічний комплекс підвищеної прохідності на базі одноплатного комп’ютера **Raspberry Pi 5**. Платформа розроблена для виконання завдань у складних, небезпечних або важкодоступних для людини умовах (розвідка, екологічний моніторинг, інженерні та рятувальні місії).

---

## 🛠 Головні особливості

* **Гібридний рушій (Гексапод із колесами):** Синергія крокуючого та колісного рушіїв. Передні (P1) та задні (P6) пари ніг оснащені звичайними колесами для швидкого пересування рівними поверхнями, а середні пари (P2, P5) виконані як чисті крокуючі кінцівки для долання перешкод.
* **Скелетизована конструкція:** Каркас зібраний із чорних та анодованих синіх алюмінієвих профілів і трубок без зовнішніх панелей, що забезпечує легкість та відкритий доступ до електроніки. Суглоби та сегменти ніг мають спеціальні «віконця» для полегшення ваги, виготовлені за допомогою **3D-друку**.
* **Навігаційна система:** Централізований лідар (LiDAR) інтегрований під верхньою монтажною конструкцією для побудови 3D-карт (SLAM) та просторової навігації.
* **Швидка модульність:** Над лідаром розташована кастомна А-подібна опора (без зайвих візерунків) та універсальна алюмінієва пластина для швидкого монтажузмінного корисного обладнання.

---

## ⚙️ Технічна специфікація

| Компонент | Опис / Модель |
| :--- | :--- |
| **Головний контролер** | Raspberry Pi 5 |
| **Периферія / Мікроконтролери** | Raspberry Pi Pico / micro-ROS |
| **Тип шасі** | Відкритий каркас (алюмінієві профілі + 3D-друк) |
| **Кінематика** | 6-ногий гексапод (4 гібридні колісні ноги, 2 крокуючі) |
| **Навігація** | LiDAR (розташований під верхньою монтажною платформою) |
| **Інтерфейс модулів** | Верхня алюмінієва монтажна пластина |
